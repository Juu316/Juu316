# 💫 About Me

I build the parts of a business that have to be right: payments, signed contracts, stock counts — for a tour operator and a jewelry shop in Mongolia.

Since December 2025 I've been a full-stack developer at **Mon Thai Sino Group (GTC Mongolia)**. There, another developer and I built the company's booking, e-contract and payment system, and I moved **orchuulga.mn** to a new stack on my own. Outside that job I built websites for a jewelry shop and a dental clinic as freelance work.

- 🌟 Full-stack developer at **GTC Mongolia** — global-travel.mn and orchuulga.mn
- 💎 Freelance: **shuren.mn** storefront and admin portal, built alone
- 🦷 Freelance: **Degfim Dental Group** one-page website, built alone
- 🎓 Graduate of **Pinecone Academy** — Full Stack Software Engineer programme
- 🐧 I work on Linux (Debian)
- 🌏 English (IELTS 7), Japanese (beginner)
- 📍 Ulaanbaatar, Mongolia
